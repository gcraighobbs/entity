# Entity

Entity is a gallery of extinct species: an AI-generated image and video for each species, with its scientific and common name, the year it was last seen, where it lived and why it disappeared. It was first shown as an art installation in 2025.

## Status

Phase A, the migration, is in progress. The site is moving to Vercel, media to Cloudflare R2, and the species catalog to a JSON file in this repo, so nothing is left that can pause.

Live: [entity-three.vercel.app](https://entity-three.vercel.app) (builds and loads; species return in A3)
